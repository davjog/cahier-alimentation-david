Ajoutez ce fichier `index.html` à la racine de votre dépôt GitHub. Votre repo doit contenir : ``` / ├── index.html ← nouveau, redirige automatiquement ├── cahier_beaufort.html ← votre application ├── manifest.json ├── icon-192.png └── icon-512.png ``` Dès que vous visitez l'URL GitHub Pages, la redirection se fait instantanément vers `cahier_beaufort.html`.
